# DisputeDesk AI

An AI agent that reads bank customer dispute complaints, extracts the key details,
checks them against real transactions, and routes unclear cases to a human.

**Stack:** Java 21 · Spring Boot · Spring AI · PostgreSQL · Node.js (Express)

## Status
🚧 In progress – building in 5 days

## Architecture
User → Node.js front end → Spring Boot backend → OpenAI + PostgreSQL
